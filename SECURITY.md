# Security

The bundled application is offline and does not send data to a server. Source links
open only when selected. Never commit external personal records, credentials or API
keys. `data/external/` is ignored by git, but review any other output before publishing.

For a suspected vulnerability, contact the repository owner privately or use GitHub
private vulnerability reporting when enabled. Do not include secrets or personal
records in public issues. CodeQL and CI configuration are supplied without claiming
that remote scans have run.
